# PUBG Drop Assistant v0.3 (오프라인)

v0.2의 지도 클릭/프로젝트 저장/녹화 영상 템플릿 추적 기능을 유지하고, **실측 참조** 모드를 추가했습니다.

## 실측 근거
사용자가 제공한 에란겔 1회 낙하 기록을 `empirical.py`에 시간별 샘플로 옮겼습니다. HUD 절대 고도 1499→49m, 출발점부터 누적 수평 경로 0→1125m, 총 39초, Shift 23초, 낙하산 26초, 기록된 HUD 최대 속도 232km/h입니다. 중간값은 선형 보간합니다. 모든 초의 원본 데이터를 전사한 것이 아니라 주요 시점만 발췌한 **부분 표본**입니다.

## 추천 지점의 의미 (중요)
- v0.3 기본 모드는 선택한 600/750/900/1125m 원과 비행기 경로의 교차점을 찾아 이탈 후보를 표시합니다. 선호 반경이 불가능하면 다른 반경을 시도하고, 모두 불가능하면 최단 접근점을 표시합니다.
- 이 위치는 **물리적으로 최적임이 검증된 이탈 지점이 아닙니다.** 39초 기록은 단일 조작 궤적이며 다른 거리, 각도, 지형 고도에 그대로 적용할 수 없습니다.
- 비행기 속도 100m/s 기본값은 아직 검증되지 않은 입력 가정이며 이탈까지 대기시간에만 사용합니다. 35초, 38m/s는 기존 레거시 모드의 가정값입니다.
- 목표 지형 절대 고도 49m는 실측 장소 기준 초기값입니다. 다른 위치에선 실제 고도로 변경하세요.
- 일반 자유낙하와 급강하, 낙하산 구간은 관측치로 표시할 수 있지만 현재는 여러 조작 전략을 시간 기반으로 최적화할 만큼 데이터가 없습니다. 그래서 **예상 착륙 시간을 의도적으로 표시하지 않습니다.**

## 사용
`run_windows.bat` 또는 `python app.py`. Windows EXE는 `build_windows.bat` 실행 후 `dist/PUBG_Drop_Assistant.exe`에서 찾습니다. Python 3.11/3.12 권장.

## 안전 범위
저장된 영상만 분석합니다. 실시간 게임 캡처, 인게임 오버레이, 게임 메모리 접근, 입력 자동화 기능은 없습니다.
